# 几猫国产 3A 大作

单文件浏览器 3D 射击游戏。保留提供的 V1 HTML 原始内容，以 `index.html` 作为网站入口。

## 运行

直接用支持 WebGL 的现代浏览器打开 `index.html`，或在本目录运行：

```sh
python3 -m http.server 8080
```

然后访问 http://localhost:8080 。点击游戏中的开始按钮进入，具体按键参见游戏内操作说明。

## 技术特点

- 内嵌 Three.js，无需安装 npm 依赖或下载 CDN 资源。
- 本地单人玩法，程序化场景与材质、实时光影、雨水和粒子效果。
- 使用 Web Audio 合成音效与音乐。
- 包含键鼠、触屏操作和画质设置。

## 部署

Vercel 使用 Other（静态网站）配置，根目录为仓库根目录，无需构建命令。连接 GitHub 仓库后，main 分支更新自动部署。

## 文件说明

`index.html` 为原始游戏文件的逐字节副本，仅重命名。原文件中的作者信息及第三方声明保持原样。
